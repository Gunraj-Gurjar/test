## 🚀 About Project

This is a simple **Basic Calculator** written in C language.  
It performs:

🔹 Addition  
🔹 Multiplication  

Built using basic functions and clean structure.

---

## 📂 File Structure

```
calculator.c
```

---

## 🛠️ Functions Used

| Function | Work |
|----------|------|
| `sum(a,b)` | Returns addition of two numbers |
| `mul(a,b)` | Returns multiplication of two numbers |

---

## ▶️ How to Run

```bash
gcc calculator.c -o calculator
./calculator
```
